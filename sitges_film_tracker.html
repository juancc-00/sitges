Estructura para tu repositorio GitHub

Esta página es 100% estática y funciona automáticamente en GitHub Pages. Solo necesitas organizar tu repositorio con esta estructura:

📁 mi-repo-sitges/
├── 📄 index.html (este archivo)
├── 📄 data.json (vuestro JSON con las películas)
└── 📁 pics/
├── 🖼️ 2024.jpg
├── 🖼️ 2025.jpg
└── 🖼️ 2026.jpg
  • Portadas automáticas: Si en el JSON aparece "sitges_year": 2026, la web buscará automáticamente la imagen pics/2026.jpg.
  • Fallback incluido: Si aún no habéis subido la foto de algún año a pics/, se generará un póster conmemorativo automáticamente para que nunca se vea una imagen rota.
  • Actualización: Cada vez que alguien añada una película a data.json y haga commit, la web mostrará los cambios al instante.
